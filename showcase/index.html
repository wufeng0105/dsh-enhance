一页读懂 dsh-enhance

给完全没听过它的人准备的读图指南：12 张图按顺序回答 6 个问题——它是什么、插在哪、一条消息怎么走、装与退怎么执行、凭什么相信它、边界在哪。每张图只新增一个概念；不想读长文时，从第 1 张往下看即可。

先读这一段

dsh-enhance 是 DeepSeek Harness 的本地增强件：把「内容边界注入」「审批三态开关」「设置页」做成可开关、可验证、可退出的三件事。它不改宿主代码，只通过 profile patch 里的几行接入；开关与文本住在 <home>/enhance/ 的两个文件里；门禁与负例保证「说的」和「做的」是同一件事；装与卸按行级手术执行，干净路径逐字节还原。

01 · ARCHITECTURE

它插在宿主哪里

enhance 不碰宿主代码：宿主启动时读 profile patch 里的三行 insert 与一个权限替换行，这几行用相对路径指向 <home>/enhance/。

02 · SEQUENCE

一条消息的一生

内容边界不是插件往对话里塞字：宿主装配系统提示时，插件把自己的段落接在末段；证据在会话日志的 system 事件里。

03 · ARCHITECTURE · 数据流

开关与文本只住在这两个文件里

state.json 存三个开关，content-scope.txt 存内容边界；插件每次装配重读，派生结果只有「注入」或「带着原因不注入」。

04 · FLOWCHART

为什么这次没有注入

四道门按顺序问：总开关、内容边界开关、文本非空、文本不超过 8 KB。第一个「否」就是原因，后面的门不再问。

05 · STATE MACHINE

审批三态：拿到请求之后回什么

这个开关不管权限范围，只管 approval/request 递过来之后回什么：allow → allowed-once，ask → 交还宿主，deny → rejected。

06 · 自定义 · patch 手术

安装只做行级追加

装的时候不重写 cordis.patch.yml：只在末尾追加一个 insert 块，再补权限表与 desktop 的替换行；已有行一个字节不动。

07 · 自定义 · 归属账本

卸载怎么知道哪一行是我们加的

install-manifest.json 记下「我们改了什么」；卸载按字段决定动作，清单丢了也不猜——逐字节认领，认不出就保留并告警。

08 · FLOWCHART

安装的四种结局

依次判断宿主根、enhance/、清单可读性与版本；四种结局各自明确：安装、只校验、更新、拒绝——没有「装一半也算成功」。

09 · PROCESS

卸载三档：默认、彻底、单档回滚

默认先归档再删目录、保留所有 .bak-*；--thorough 是不归档的不可逆选项；--to 只回滚一个 profile 的 patch。

10 · PROCESS

门禁与负例：绿不是信，能红才是

七道 fast 门禁串成一条链；绿灯只说明「这次没抓到」。真正证明门禁活着的是负例：在副本上把守卫改回旧写法，它必须变红。

11 · PROCESS

版本与升级：一个版本号，三处比对

版本只有 VERSION 一个来源；安装把它写进清单，doctor 拿清单比当前；宿主升级后另有一件事要查——派生件是不是同一代。

12 · 自定义 · 失败矩阵

失败矩阵：每个坑由谁发现

门禁和 doctor 不是万能的：五行失败形态里，标出来的那一行合并了两条设计边界——没有自动检测，只能人工核对。

已知限制（不假装被覆盖）

  • 宿主档位是 approval: never 时，审批请求根本不发，三态都轮不到。
  • patch 只做行级追加、不解析整份 YAML：结构坏要靠人看。
  • 无 Origin 的请求（curl / CLI）直接放行；接口没有额外 token。
  • 会话探针只读最新一份会话：多工作区并行时可能读错对象。
  • doctor 只验派生件带没带来源戳；「同一代」要靠 build-client --check --asar。
  • 文本上限在写入与读取两侧都生效；超限不注入，doctor 判红。

自己跑一遍

node install.mjs   --home <DSH_HOME> --dry-run   # 先看要写什么
node install.mjs   --home <DSH_HOME>             # 装（有变化才备份 patch）
node doctor.mjs    --home <DSH_HOME>             # 全 PASS 再重启
node uninstall.mjs --home <DSH_HOME>             # 卸载（默认归档、保留备份）
node scripts/check.mjs --layer full             # 七道门 + 两道 full
